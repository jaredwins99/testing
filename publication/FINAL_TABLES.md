# Final Supplement tables

Generated by `publication/scripts/final_tables.R` from
`publication/forest_data_adj_95ci_fixed.csv` — the same file the forest plots read.
Rebuild with:

```
Rscript publication/scripts/final_tables.R
```

Ordered as they appear in the Supplement. Each entry gives the rendered table
for reading and the LaTeX beneath it for pasting.

## How these were selected

Every rule is taken from the renderers, so the tables cannot disagree with the figures:

- point estimate is the posterior **median**, matching `exp(median)` on the plots
- a pooled estimate is **dropped when fewer than two restaurants contribute**
- T1 A2 breakfast-style meat / Presence is dropped (both contributing restaurants
  are atypical on the control series, so the pooled sits outside both)
- outcome order and labels come from the renderers' own vectors:
  **`untextured` = Ground meat**, **`textured` = Whole-muscle meat**
- whole-muscle is not shown in A2 in either tier
- `---` marks a cell whose pooled estimate was suppressed by the rules above

Row counts reproduce the diagram and the Methods total independently:
**30 + 4 + 10 + 2 = 46 reported Tier One effects**.

All values are ratios of rate ratios (RRR) — outcome effect minus total-purchases
effect, differenced draw by draw — except A5/A6, which use an identity link and are
reported on the original scale.
